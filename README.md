Solana Bay is an open-world coastal crime game that runs in a desktop browser from its own
static files, with no build step and no network request. You play Mateo Reyes across four
districts of a sun-soaked fictional coast: on foot, behind the wheel of six vehicle classes,
with lane-following traffic, pedestrians, a five-star police response, a six-mission story
chain, three firearms, a live minimap with GPS routing, synthesized audio, and a career save.

## Controls

WASD to move and drive, F to enter or steal a car, left mouse to shoot, 1-4 to switch weapons,
space to jump or drift, M or Escape for the map and menu.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
